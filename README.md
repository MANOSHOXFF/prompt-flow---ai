## ✨ Sobre o projeto

O **Prompt Flow AI** reúne recursos para trabalhar com prompts em uma experiência social, permitindo publicar, descobrir e organizar conteúdos dentro da plataforma.

## 🚀 Recursos documentados

- 🖼️ **Galeria** — exploração de prompts publicados
- ❤️ **Curtidas** — interação com prompts
- 🔖 **Favoritos** — salvar prompts para acessar depois
- ✍️ **Publicação de prompts** — compartilhar prompts na plataforma
- 👤 **Perfis** — páginas de perfil dos usuários
- 👥 **Seguir usuários** — acompanhar outros perfis
- 🔔 **Notificações** — acompanhar atividades relevantes
- 🏆 **Níveis de perfil** — Artesão e Mestre
- 🎨 **Personalização de temas**
- 📱 **Interface adaptada para diferentes tamanhos de tela**, incluindo tablets

> Esta documentação lista somente recursos já definidos no projeto. Não foram adicionadas funcionalidades fictícias.

## 🏆 Níveis

O projeto possui os níveis **Artesão** e **Mestre**. O nível Mestre utiliza o marco de **360 curtidas** definido no projeto.

## 🎨 Temas

Entre os temas definidos para o aplicativo estão **Galáxia**, **Céu** e **Material You**. O aplicativo também possui opções de tema do sistema, escuro e claro (Beta).
